# Loren Metais, visual novo (Loja Integrada)

CSS e JS que redesenham a loja lorenmetais.com.br por cima do tema da Loja Integrada, sem mudar o checkout.

- `loren.css`: visual novo, todo dentro de `html.lm-novo` (sem a classe, o site fica como está).
- `loren.js`: liga a classe e troca a logo. Não roda no checkout.
- `brand-tokens.css`: cores, fontes e medidas do brand kit Loren Metais.

Servido pelo jsDelivr: `https://cdn.jsdelivr.net/gh/Lorenmetais/loren-metais-front@<commit>/loren.css`
